Prueba de animaciones del protagonista

Fuente: 01-TBE/images/caracters.gif (filas 1 y 2). Cada frame se recorta como una celda fija de px alineada abajo-centro (igual que lo haría Sprite en el juego).

1. Frames detectados

A = fila 1, B = fila 2. Las celdas amarillas son lo que se recorta para cada frame.

2. Animaciones

Puedes editar las secuencias. Formato: A0,A1,B3; añade m para espejar (p.ej. A1m).

3. Prueba jugable

Mueve al personaje con flechas o WASD. Usa las secuencias de arriba.
